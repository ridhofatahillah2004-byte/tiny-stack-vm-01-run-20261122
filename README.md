One `main.ts` that runs every program of the tiny stack ISA (32-bit wrapping integers, 256-value stack, calls, 256 words of memory, all ten traps, step and output limits) and writes each program's exact output bytes and exit code.

Practice: score **1,000,000** (40/40); baseline plain-vm 1.0.0: 670,000.
